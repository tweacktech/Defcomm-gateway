Introduction

Two services, one platform

Defcomm provides two independent real-time communication services, each with its own SDK:

📹
Defcomm Meet
@defcomm/meet-sdk
Video & audio conferencing with screen sharing, recording, waiting rooms, and chat. Up to 200 participants per room.
📞
Defcomm Calls
@defcomm/calls-sdk
Audio-only calls with a four-tier priority system. Emergency calls bypass all restrictions and cannot be declined.
🔒 All media (audio/video) travels peer-to-peer via WebRTC and never passes through Defcomm's servers. The server only handles signaling, presence, and metadata.
Setup

Installation

Terminalbash
# Install one or both SDKs
npm install @defcomm/meet-sdk
npm install @defcomm/calls-sdk
1
Generate an API token
In your Defcomm dashboard: Settings → API Tokens → New Token. Copy the token — it's shown once. This token is used for all server-side operations.
2
Set the environment variable
Store the token securely on your server. Never include it in browser code or commit it to source control.
.envenv
DEFCOMM_URL=https://meet.yourcompany.com
DEFCOMM_API_TOKEN=sk-1234abcd...
DEFCOMM_APP_KEY=your-laravel-app-key   # for webhook verification
3
Initialize the SDK on your server
server.tsts
import DefcommMeet  from '@defcomm/meet-sdk';
import DefcommCalls from '@defcomm/calls-sdk';

export const meet = new DefcommMeet({
  serverUrl: process.env.DEFCOMM_URL,
  apiToken:  process.env.DEFCOMM_API_TOKEN,
});

export const calls = new DefcommCalls({
  serverUrl: process.env.DEFCOMM_URL,
  apiToken:  process.env.DEFCOMM_API_TOKEN,
});
Authentication

Tokens & security model

Defcomm uses a two-token model: a long-lived API token for server operations, and short-lived join tokens for participants.

⚠️ The API token must only be used on your server. If exposed in browser code, anyone can create rooms, end calls, and access recordings under your account.
Token flowts
// ① Your server creates a room/call and issues a join token
const { room, joinToken } = await meet.createRoom({ name: 'Q3 Planning' });
const { token } = await meet.issueToken(room.uid, {
  displayName: user.name,
  userId:      user.id,
  role:        'participant',     // or 'host', 'co-host', 'viewer'
});

// ② Send token + roomUid to your frontend (never the API token!)
res.json({ roomUid: room.uid, token });

// ③ Frontend embeds the room — no API token required
const sdk = new DefcommMeet({ serverUrl: DEFCOMM_URL });
sdk.embed('#room', { roomUid, token });

Join tokens expire after 2 hours. The bearer API token does not expire — rotate it in Settings if compromised.

Meet SDK

Quick start

api/meeting.tsts
import { meet } from './sdk';

// Create a room + issue a host token in one call
app.post('/api/meeting/start', async (req, res) => {
  const { room, joinToken } = await meet.createRoom({
    name:             'Customer Support — Ticket #' + req.body.ticketId,
    waitingRoom:      true,      // host admits each participant
    recordingEnabled: true,
    webhookUrl:       'https://yourapp.com/webhooks/meet',
    webhookEvents:    ['room.started', 'room.ended', 'recording.ready'],
  });

  // Issue separate tokens for host and participant
  const { token: participantToken } = await meet.issueToken(room.uid, {
    displayName: req.user.name,
    userId:      req.user.id,
    role:        'participant',
  });

  res.json({
    roomUid:          room.uid,
    hostToken:        joinToken,          // for the agent
    participantToken,                     // for the customer
    joinUrl:          room.joinUrl,
  });
});

Meet SDK

Webhooks

webhook handler (Express)ts
import DefcommMeet from '@defcomm/meet-sdk';

app.post('/webhooks/meet', express.raw({ type: '*/*' }), (req, res) => {
  const body = JSON.parse(req.body.toString());
  const sig  = req.headers['x-defcomm-signature'];

  // Verify HMAC-SHA256 signature
  if (!DefcommMeet.verifyWebhook(body, sig, process.env.DEFCOMM_APP_KEY)) {
    return res.sendStatus(401);
  }

  switch (body.event) {
    case 'room.started':
      await db.meetings.update(body.room_uid, { status: 'active' });
      break;
    case 'room.ended':
      await db.meetings.update(body.room_uid, {
        status:   'ended',
        ended_at: body.payload.ended_at,
      });
      break;
    case 'recording.ready':
      await notifyHost(body.payload.download_url);
      break;
  }

  res.sendStatus(200);
});

Available webhook events: room.started · room.ended · participant.joined · participant.left · participant.kicked · recording.started · recording.ready

IncomingCallHandler.tsxtsx
// Mount in your root layout to receive incoming calls globally.
// Listens on the personal Reverb channel: private-user.{id}

import { useEffect, useState } from 'react';
import Echo from 'laravel-echo';

export function IncomingCallHandler({ userId }) {
  const [incoming, setIncoming] = useState(null);

  useEffect(() => {
    const echo = new Echo({ broadcaster: 'reverb', ... });

    echo.private(`user.${userId}`)
      .listen('.call.initiated', (data) => {
        setIncoming(data);
        // Emergency calls auto-answer in 5s
        if (data.priority === 'emergency')
          setTimeout(() => answerCall(data.uid), 5000);
      });

    return () => echo.leave(`user.${userId}`);
  }, [userId]);

  if (!incoming) return null;

  return (
    <IncomingCallToast
      call={incoming}
      onAnswer={() => router.push(`/calls/${incoming.uid}`)}
      onDecline={() => axios.post(`/calls/${incoming.uid}/decline`)}
    />
  );
}
Calls SDK

Priority system

Every call has a priority that controls how the callee experiences the incoming call. Priority can be escalated mid-call.

P0
Routine
Normal ring. Callee can decline or ignore. Suitable for planned check-ins and non-urgent matters.
P1
Important
Visual flag shown. Call is logged for audit. Callee can still decline. Use for escalations that need attention within the hour.
P2
Urgent
Overrides Do Not Disturb. Auto-answers after 30 seconds if the callee doesn't respond. Cannot be snoozed.
P3
Emergency
Cannot be declined. The decline button is hidden. Auto-answers in 5 seconds. Bypasses all restrictions. Reserved for critical security incidents and system failures.
⚠️ Use Emergency priority sparingly. Overuse desensitises recipients and undermines the trust model. It should be reserved for situations requiring an immediate human response regardless of context.
Escalate mid-callts
// A routine check-in escalates when an incident is detected
await calls.changePriority(callUid, 'emergency', 'Active breach detected on prod-db-01');

// All participants' UIs update instantly:
// — Priority bar changes colour
// — Note appears as a banner
// — Participants who hadn't joined get the emergency overlay

Shared

Webhook verification

Every webhook request includes an X-Defcomm-Signature header. Verify it using your app key to prevent spoofing.

Verification (Node.js)ts
import crypto from 'crypto';

function verifyWebhook(
  body: { room_uid?: string; call_uid?: string; timestamp: number },
  signature: string,
  appKey: string,
): boolean {
  const uid      = body.room_uid ?? body.call_uid ?? '';
  const expected = crypto
    .createHmac('sha256', appKey)
    .update(uid + String(body.timestamp))
    .digest('hex');
  return crypto.timingSafeEqual(
    Buffer.from(expected),
    Buffer.from(signature),
  );
}
💡 Both SDKs expose DefcommMeet.verifyWebhook() and DefcommCalls.verifyWebhook() as static methods that do this for you.

Incident response flow (Calls)ts
// Your monitoring system detects an incident
async function onAlertFired(incident: Incident) {
  // Start as urgent — escalate to emergency if no response
  const { call } = await calls.create({
    mode:         'one_to_one',
    calleeId:     incident.oncall_user_id,
    priority:     'urgent',
    priorityNote: `[${incident.severity}] ${incident.title}`,
    muteOnJoin:   false,
    webhookUrl:   'https://yourapp.com/webhooks/calls',
  });

  // If no answer in 60s, escalate to emergency
  setTimeout(async () => {
    const { call: current } = await calls.get(call.uid);
    if (current.status === 'pending') {
      await calls.changePriority(
        call.uid, 'emergency',
        'No response — escalating. Auto-answer in 5s.'
      );
    }
  }, 60_000);
}
